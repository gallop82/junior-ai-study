# 初中英语 200 句资料包

本资料包由 `200sentence` 原始 JSON 数据整理而成，放置于 `junior-english-study/references` 下，主要用于句子讲解、场景背诵、写作积累和词块提取。

## 数据概况

- 句子数：200
- 词汇条目数：741
- 短语条目数：602
- 场景标签数：138
- 语法标签数：200

## 文件说明

- `README.md`：资料包总说明
- `teacher-directory.md`：本资料包目录索引
- `sentences-overview.md`：200句完整总表，适合通读、检索和抽句
- `scene-index.md`：按核心场景归类，适合主题背诵和口语、写作积累
- `word-bank.md`：按字母排序整理的词汇表
- `phrase-bank.md`：按字母排序整理的短语表
- `sentences.json` / `words.json` / `phrases.json`：保留的原始结构化数据

## 建议用法

- 想讲解句子：优先查 `sentences-overview.md`
- 想按场景积累：优先查 `scene-index.md`
- 想积累词汇和词块：优先查 `word-bank.md` 与 `phrase-bank.md`
- 想做程序处理或二次整理：直接读取 JSON 文件
