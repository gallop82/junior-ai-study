# 安徽中考语文作文评分标准（2026版）

**总分：55分**

## 一、评分原则

1. **分项分等评分**：从「内容、表达、书写」三个维度，按五个等级综合评定。

2. **先定等级，再定分数**：阅卷老师先整体判定作文所属等级，再在该等级分值区间内打分。

3. **双人阅卷**：两人独立评分，分差≤5分取平均分；分差>5分，由阅卷中心组裁定。

4. **扣分规则**：
        

    - 无标题/标题不完整：扣2-3分

    - 字数不足：每少50字扣1-2分；不足400字降一等

    - 错别字：每3个扣1分（重复不计）

    - 标点错误：每处扣0.5分

    - 泄露真实姓名、校名：扣1-3分

## 四、高分作文关键要点

1. **审题精准**：抓住题眼，不偏题、不离题。

2. **立意深刻**：中心明确、积极向上，有独特视角与深度。

3. **内容充实**：选材新颖、具体，有细节，情感真实动人。

4. **结构清晰**：开头点题、中间分层、结尾升华，过渡自然。

5. **语言出彩**：流畅、生动、准确，善用修辞，避免空话套话。

6. **书写规范**：字迹工整，卷面整洁，减少涂改。
