# 第六单元 近代化的早期探索与民族危机的加剧

## 单元主线

这一单元讲的是：在列强不断侵略和民族危机不断加深的背景下，中国人开始了近代化的早期探索。

可以理解成四条线：

1. 洋务派学习西方技术，发起洋务运动，中国近代化开始起步
2. 日本发动甲午中日战争，中国半殖民地化程度大大加深
3. 资产阶级维新派发动戊戌变法，尝试制度变革
4. 义和团和清政府共同抗击八国联军，最终《辛丑条约》使中国完全陷入半殖民地半封建社会深渊

## 内容框架

- 洋务运动
- 左宗棠收复新疆
- 甲午中日战争与列强瓜分中国狂潮
- 戊戌变法
- 八国联军侵华与《辛丑条约》签订

## 时间线

- 19世纪60年代到90年代中期：洋务运动
- 1875年：左宗棠率军收复新疆
- 1884年：清政府在新疆建省
- 1894年：甲午中日战争爆发
- 1895年：《马关条约》签订
- 1895年：公车上书
- 1898年：百日维新开始
- 1900年：八国联军侵华战争爆发
- 1901年：《辛丑条约》签订

## 一、洋务运动

### 1. 背景和目的

- 时间：19世纪60年代到90年代中期
- 目的：利用西方先进技术，强兵富国，维护清王朝统治

### 2. 代表人物

- 中央：奕䜣
- 地方：曾国藩、李鸿章、左宗棠、张之洞

### 3. 口号

- 自强
- 求富

### 4. 内容

#### 军事工业

- 以“自强”为口号
- 创办安庆内军械所、江南制造总局、福州船政局等

#### 教育

- 兴办新式学校
- 培养翻译和军事人才
- 设立翻译馆
- 派遣留学生出国深造

#### 民用工业

- 以“求富”为主张
- 开办轮船招商局、开平煤矿、汉阳铁厂、湖北织布局等

#### 新式军队

- 组建新式洋枪队
- 采用西式兵操练兵
- 建成福建、广东、南洋、北洋等海军
- 1885年成立海军衙门统一协调指挥
- 同年在台湾建立行省

### 5. 评价

- 洋务运动是中国历史上第一次近代化运动
- 客观上促进了中国民族资本主义的产生
- 对外国资本入侵起到一定抵制作用
- 但根本目的是维护清政府统治
- 最终没有使中国走上富强道路

### 6. 这一运动为什么重要

- 它是中国工业化的起点
- 让中国人第一次大规模接触近代机器工业

## 二、左宗棠收复新疆

### 1. 新疆危机

- 19世纪70年代，新疆大部分地区被中亚浩罕国将领阿古柏占领
- 俄国还出兵侵占伊犁

### 2. 收复过程

- 1875年，左宗棠采取“先北后南，缓进急战”的策略
- 率领装备新式武器、接受新式训练的清军，成功收复新疆

### 3. 结果

- 1884年，清政府在新疆建立行省

### 4. 意义

- 维护了国家领土完整
- 巩固了西北边疆

## 三、甲午中日战争与列强瓜分中国狂潮

### 1. 甲午中日战争

#### 背景

- 征服朝鲜是日本侵略中国、称霸世界的重要步骤
- 1894年朝鲜发生东学党起义，清政府应朝鲜请求出兵，日本乘机挑起战争

#### 爆发

- 1894年7月，日本舰队在朝鲜丰岛海面袭击清军运兵船

#### 主要战役

- 平壤战役：左宝贵牺牲，叶志超弃城逃跑
- 黄海海战：邓世昌率舰直冲敌舰，壮烈殉国
- 辽东半岛战役：日军占领大连、旅顺，旅顺发生大屠杀
- 威海卫战役：丁汝昌自杀殉国，北洋舰队全军覆没

### 2. 《马关条约》

#### 内容

- 割辽东半岛、台湾全岛及所有附属岛屿、澎湖列岛给日本
- 赔偿日本兵费白银2亿两
- 开放沙市、重庆、苏州、杭州为商埠
- 允许日本在通商口岸开设工厂

#### 影响

- 外国侵略势力进一步深入中国腹地
- 大大加深中国半殖民地化程度

### 3. 列强瓜分中国狂潮

#### 背景

- 《马关条约》签订后，沙俄联合法法德迫使日本放弃辽东半岛
- 列强趁机在中国掀起抢夺利权、强租海港、划分势力范围的瓜分狂潮

#### 门户开放政策

- 美国承认各国在中国的势力范围和既得特权
- 同时要求在各国租借地和势力范围内享有均等贸易机会

### 4. 甲午战争后的中华民族觉醒

- 政治上：维新变法开始，学习西方民主政治
- 经济上：张謇走上“实业救国”道路
- 思想上：严复宣传“物竞天择，适者生存”

## 四、戊戌变法

### 1. 公车上书

- 1895年，康有为、梁启超等发起公车上书
- 拉开变法维新运动序幕
- 维新人士组织学会，创办报刊，其中影响最大的是《时务报》和《国闻报》

### 2. 百日维新

#### 背景

- 1897年冬，德国强占胶州湾
- 康有为上书光绪帝，呼吁变法救国

#### 开始标志

- 1898年6月11日，清政府颁布“明定国是”诏书

#### 内容

- 政治：裁撤冗官冗员，允许官民上书言事
- 经济：鼓励私人兴办工矿企业，发展农工商；改革财政，编制国家预算
- 文化：废除八股，改试策论，开办新式学堂
- 军事：裁减绿营，训练新式军队

#### 评价

- 政治上有利于维新人士参与政治
- 经济上有利于民族资本主义发展
- 文化上有利于传播西方科学文化
- 军事上有利于增强国防实力

### 3. 戊戌政变

- 1898年9月21日，慈禧太后等发动政变
- 囚禁光绪帝，搜捕维新人士，废除变法诏令
- 谭嗣同、刘光第、林旭、杨锐、杨深秀、康广仁被杀，史称戊戌六君子

### 4. 意义和性质

- 虽然失败了，但在思想文化方面产生广泛而持久的影响
- 使更多人了解和接受资产阶级维新思想
- 起到思想启蒙作用
- 是一次资产阶级改良运动，也是一次思想启蒙运动

## 五、八国联军侵华与《辛丑条约》签订

### 1. 义和团运动

#### 兴起

- 由山东、直隶一带的义和拳、民间秘密结社和练拳习武组织发展而来
- 19世纪末逐渐转变为广泛群众性的反帝斗争组织

#### 发展

- 1900年夏，义和团控制京津地区

#### 口号

- 扶清灭洋

#### 局限性

- 对清政府本质认识不清
- 盲目排斥西方文化
- 带有迷信色彩

#### 结果和意义

- 在中外反动势力联合镇压下失败
- 但沉重打击了帝国主义瓜分中国的野心

### 2. 抗击八国联军

#### 八国联军侵华

- 目的：镇压义和团运动，维护和扩大帝国主义在华利益
- 1900年6月，英美俄日法德意奥组成八国联军进犯北京

#### 中国军民抵抗

- 义和团破坏沿线铁路，在廊坊一带阻击敌人
- 义和团和清军围攻西什库教堂和东交民巷使馆区
- 天津保卫战中，聂士成壮烈殉国

### 3. 《辛丑条约》

#### 时间

- 1901年

#### 内容

- 经济：赔款白银4.5亿两，本息共9.8亿两
- 政治：严禁人民参加反帝活动
- 军事：拆毁大沽炮台，允许外国军队驻扎铁路沿线要地
- 外交：划定东交民巷为使馆界，允许各国派兵驻守
- 行政：改总理衙门为外务部，班列六部之前

#### 危害

- 赔款最庞大，主权丧失最严重
- 清政府完全沦为帝国主义列强统治中国的工具
- 中国完全陷入半殖民地半封建社会深渊

## 六、这一单元最容易混的点

### 1. 洋务运动和戊戌变法要区分

- 洋务运动重在技术和器物层面
- 戊戌变法重在制度和思想层面

### 2. 甲午战争和第二次鸦片战争不是一回事

- 甲午战争：日本侵华
- 第二次鸦片战争：英法等列强侵华

### 3. 《马关条约》和《辛丑条约》要分清

- 《马关条约》大大加深半殖民地化
- 《辛丑条约》使中国完全陷入半殖民地半封建社会深渊

### 4. 义和团的口号要会解释

- 扶清：对清政府抱有幻想
- 灭洋：反对帝国主义

## 七、因果链

- 列强侵略加剧 -> 洋务运动兴起 -> 近代化开始
- 新疆危机 -> 左宗棠收复新疆 -> 巩固边疆
- 日本侵华野心 -> 甲午中日战争 -> 《马关条约》 -> 半殖民地化加深
- 民族危机加深 -> 公车上书 -> 戊戌变法 -> 思想启蒙
- 八国联军侵华 -> 《辛丑条约》 -> 中国完全陷入半殖民地半封建社会

## 八、速记句

- 洋务自强又求富，近代化路先起步
- 左宗棠先北后南收新疆
- 甲午战败马关辱，半殖民地更加深
- 公车上书开变法，百日维新终失败
- 扶清灭洋义和团，辛丑条约最屈辱
