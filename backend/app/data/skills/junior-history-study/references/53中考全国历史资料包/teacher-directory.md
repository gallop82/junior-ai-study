# 53中考全国历史资料包总入口

这是一份给大模型和学习者共用的总入口。先按主线找单元，再进入对应 `unit-xx.md` 读取正文；遇到跨单元问题，再结合专题整合和附录方法。

## 一、阅读顺序

1. 先看总入口，判断问题属于中国古代史、中国近代史、中国现代史，还是世界史。
2. 再进入对应单元，优先读 `单元概览`、`学习导图` 和 `重难点梳理`。
3. 如果是跨单元比较题，结合 `special-topic-integration.md`。
4. 如果是题型方法题，再看 `appendix.md`。

## 三、主题线

### 1. 中国史三条主线

- 从分裂走向统一：统一多民族国家形成、巩固、发展。
- 从屈辱走向独立：近代中国反侵略、求民主、争解放。
- 从建设走向复兴：新中国成立、社会主义建设、改革开放、中国特色社会主义。

### 2. 世界史三条主线

- 从殖民扩张到民族独立：世界近代殖民与殖民地反抗。
- 从工业化到现代化：工业革命、科技革命、现代社会变化。
- 从战乱对抗到和平发展：两次世界大战、冷战、全球化、多极化。
