# 第二十一单元 工业革命和国际共产主义运动的兴起

## 单元主线

这一单元讲的是工业革命怎样把人类带入工业社会，以及马克思主义和国际共产主义运动怎样在这一背景下兴起。

这章的主线可以理解成：
1. 英国首先发生工业革命，机器生产取代手工生产。
2. 工业革命推动社会进入“蒸汽时代”。
3. 资本主义快速发展，但工人处境并没有因此自动改善。
4. 马克思和恩格斯总结历史经验，创立马克思主义。
5. 无产阶级运动从此有了科学理论指导。

这章最重要的理解点是：
1. 工业革命为什么首先发生在英国？
2. 蒸汽机为什么是工业革命的核心标志？
3. 马克思主义为什么会在那个时代诞生？

## 内容框架

- 第一次工业革命
- 马克思主义的诞生和国际共产主义运动的兴起

## 时间线

- 1765年：珍妮机发明
- 1785年：瓦特改进蒸汽机投入使用
- 1825年：斯蒂芬森设计蒸汽机车试车成功
- 1848年：《共产党宣言》发表
- 1864年：第一国际成立
- 1871年：巴黎公社建立

## 一、第一次工业革命

### 1. 工业革命为什么会发生

#### 背景

- 英国君主立宪制建立后，政局稳定。
- 资本主义经济迅速发展，国内外市场扩大。
- 英国在殖民掠夺和海外贸易中积累了大量资本。
- 工场手工业中劳动分工比较细密，生产过程已为机器化准备了条件。

#### 为什么英国先发生

- 有资本积累。
- 有市场需求。
- 有技术和劳动分工基础。
- 政治环境相对稳定。

### 2. 工业革命的开始

- 1765年，哈格里夫斯发明珍妮机。
- 这通常被看作工业革命开始的标志之一。

### 3. 蒸汽机和工厂制度

#### 瓦特改良蒸汽机

- 1785年，瓦特改进的蒸汽机投入使用。
- 到19世纪30年代，蒸汽机成为主要动力来源。

#### 作用

- 蒸汽机的广泛使用是生产领域的一次意义重大的飞跃。
- 它极大提高了生产力，使工业革命得以更快向纵深发展。

#### 工厂制度确立

- 进入19世纪，传统的手工工场逐渐被大工厂替代，现代工厂制度最终确立。

#### 为什么蒸汽机这么重要

- 它让生产不再主要依赖人力、畜力和水力。
- 它使工厂能够更集中、更高效地生产。

### 4. 火车与铁路

- 1825年，由斯蒂芬森设计的蒸汽机车正式试车，标志着铁路时代开始。

#### 意义

- 为社会提供了更快捷、廉价、便利的交通。
- 使生产和市场之间的联系更加密切。

### 5. 工业革命的影响

- 工业革命极大提高了社会生产力水平。
- 人类进入蒸汽时代。
- 19世纪中期，英国成为世界上第一个工业国家。
- 从18世纪后期起，其他西方国家纷纷学习英国先进技术和生产经验，先后进行了工业革命。

#### 这场革命改变了什么

- 不只是机器变多了，而是整个社会从农业社会转向工业社会。

## 二、马克思主义的诞生和国际共产主义运动的兴起

### 1. 马克思与恩格斯

- 马克思和恩格斯在巴黎相识，一起讨论各种理论和欧洲工人运动。
- 他们批判地继承了前人思想精华，形成了马克思主义理论。

### 2. 《共产党宣言》

#### 发表时间

- 1848年

#### 主要内容

- 有文字记载的全部历史都是阶级斗争的历史。
- 资本主义社会必将被共产主义社会所取代。
- 肯定资产阶级在历史上曾起到非常革命的作用。
- 工人阶级创造了巨大的社会财富，但他们相对日益贫困。
- 号召工人阶级组织起来，建立无产阶级自己的政党。
- 用暴力推翻资产阶级统治，进行无产阶级革命。

#### 意义

- 《共产党宣言》的发表标志着马克思主义诞生。
- 从此，无产阶级的斗争有了科学理论指导，国际共产主义运动兴起并蓬勃发展。

#### 为什么它这么重要

- 它第一次把无产阶级革命和历史发展规律系统地联系起来。
- 这让工人运动从自发斗争走向自觉斗争。

### 3. 国际工人运动的兴起

#### 第一国际

- 1864年，英国、法国、德国等国的工人代表联合起来成立国际工人协会，史称第一国际。

#### 巴黎公社

- 1871年3月18日，巴黎无产阶级和人民群众举行武装起义，推翻资产阶级反动统治。
- 3月28日，建立世界上第一个无产阶级政权巴黎公社。

#### 巴黎公社的意义

- 它是无产阶级建立政权的第一次伟大尝试。
- 它丰富了马克思主义理论。

#### 为什么巴黎公社很重要

- 它说明无产阶级不仅可以斗争，还可以尝试建立自己的政权。
- 虽然失败了，但经验和教训很宝贵。

## 三、这一单元最容易混的点

- 工业革命首先发生在英国，不是法国或美国。
- 珍妮机是工业革命开始的重要标志之一。
- 蒸汽机推动工业革命进入“蒸汽时代”。
- 《共产党宣言》标志马克思主义诞生，不是第一国际。
- 第一国际是工人组织，不是理论著作。
- 巴黎公社是无产阶级政权的第一次尝试，不是马克思本人领导建立的。

## 四、因果链

- 英国资本积累 + 市场扩大 + 技术条件成熟 → 工业革命
- 工业革命 → 蒸汽机广泛使用 → 工厂制度形成
- 工业发展 → 资产阶级和无产阶级矛盾突出 → 工人运动兴起
- 马克思和恩格斯总结经验 → 《共产党宣言》 → 马克思主义诞生
- 马克思主义指导 → 第一国际 → 巴黎公社

## 五、速记句

- 珍妮机出工业起，瓦特蒸汽开新篇
- 铁路通向蒸汽世，英国首先变工厂
- 马恩相识在巴黎，共产宣言开新章
- 第一国际工人聚，巴黎公社试政权
