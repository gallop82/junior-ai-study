# 初中历史万能公式

这份材料不是给你单独的标准答案，而是把历史主观题常见的分析框架整理出来。做题时，先判断题型，再把问题放进对应的公式里，答案就会更稳。

## 一、性质分析

### 基本公式

- `任务 + 领导阶级 + 主力 + 手段 + 结果 + 结论`

### 典型思路

- 先看这个事件想完成什么任务。
- 再看由哪个阶级或力量领导。
- 再看依靠什么力量、用什么手段推动。
- 最后看结果有没有完成主要任务。
- 结论通常要落到“是什么性质的运动、革命或改革”上。

### 例子：辛亥革命

- 任务是反帝反封建，在中国独立发展资本主义。
- 由资产阶级领导，具有一定群众基础。
- 采取暴力革命手段。
- 结果推翻了封建帝制，建立了共和国。
- 但革命果实被袁世凯篡夺，没有改变中国社会性质。
- 因此可以判断，辛亥革命是一场不完全成功的资产阶级民族民主革命。

## 二、影响或意义分析

### 基本公式

- `(国内影响 + 国际影响) + (经济影响 + 政治影响 + 文化影响) + 深远影响`

### 典型思路

- 先看国内影响，再看国际影响。
- 再分别从经济、政治、文化三个方面展开。
- 经济上常看生产力、生产关系、经济结构、经济格局。
- 政治上常看世界格局、制度、体制、政权、政策、阶级关系、民族关系。
- 文化上常看思想、科技、教育、文学艺术。

### 例子

#### 经济影响公式

- `生产力 + 生产关系 + 经济结构 + 经济格局 + ……`

##### 第三次工业革命

- 极大提高社会生产力。
- 促进国家垄断资本主义发展。
- 第三产业比重上升。
- 世界经济格局多极化。

#### 政治影响公式

- `世界格局 + 制度 + 体制 + 政权 + 政策 + 阶级 + 民族 + ……`

##### 十月革命

- 改变世界政治格局。
- 建立社会主义制度。
- 实现无产阶级专政。
- 鼓舞世界无产阶级革命和民族解放运动。
- 标志世界现代史开端。

#### 文化影响公式

- `思想 + 科技 + 教育 + 文学艺术 + ……`

##### 两次鸦片战争

- “西学东渐”。
- 产生“中体西用”思想。
- 引进西方近代科学技术。
- 发展近代教育。
- 爱国主义文学兴起。

## 三、判断成败及原因

### 基本公式

- `判断成败的依据：直接目标 + 主要任务 + 根本任务`
- `成败原因：主观原因 + 客观原因 + 经济因素 + 政治因素 + 军事因素 + 策略因素`
- `成败根源：社会条件 + 阶级本质 + 进步性 + 局限性`

### 典型思路

- 先看直接目标有没有实现。
- 再看主要任务和根本任务有没有完成。
- 分析原因时，要区分主观和客观。
- 还要从经济、政治、军事、策略等方面寻找原因。
- 判断根源时，要往社会条件和阶级本质上追。

### 例子：辛亥革命

- 从推翻清朝统治、结束封建君主专制的直接目标看，它取得了成功。
- 从改变半殖民地半封建社会这一根本任务看，它没有达到。
- 成功原因包括革命派的前赴后继精神、满清政府的孤立、各派政治力量的配合。
- 失败根源包括中国半殖民地半封建社会的历史局限和民族资产阶级自身的阶级局限性。

## 四、经验教训或启示

### 基本公式

- `经验 + 教训 + 启示`

### 典型思路

- 先总结经验。
- 再总结教训。
- 最后上升到现实启示。
- 常从国情、领导、群众、武装、民主、法制、思想、策略入手。
- 经济类常从生产力、生产关系、客观规律、发展战略入手。
- 文化类常从批判、改造、继承、发展入手。

### 例子

#### 第一次国共合作

- 经验：国共两党可以合作，也取得一定成果。
- 教训：必须掌握领导权和武装。
- 启示：合作要以斗争求团结。

#### 社会主义经济建设

- 要正确认识社会主义初级阶段生产力水平。
- 生产关系调整要适应生产力发展。
- 要遵循客观经济规律。
- 注意综合平衡和可持续发展。
- 宏观调控与市场竞争结合。

#### 马克思主义中国化

- 马克思主义必须同中国具体国情相结合。
- 要在革命或建设实践探索中不断发展。

## 五、历史评价

### 基本公式

- `积极因素 + 消极因素 + 具体史实 + 结论`
- `属性 + 事迹 + 影响 + 进步性 + 局限性 + 结论`
- `概况 + 性质特点 + 影响 + 结论`

### 典型思路

- 先抓属性，也就是这个人物或事件属于什么阶级、什么类型。
- 再列举主要史实，说明做了什么。
- 接着分析积极和消极影响。
- 最后下结论，不能只说好或只说坏。
- 人物评价要注意时代性、阶级性、阶段性和全面性。

### 例子

#### 李鸿章

- 先看身份属性，即地主阶级洋务派代表人物。
- 再按时间和方面分析其在洋务运动、镇压太平天国、中法战争、中日战争中的表现。
- 再分析其积极和消极影响。
- 最后得出全面结论。

#### 事件或事态评价

- 概况。
- 性质特点。
- 影响。
- 进步性或反动性。
- 正义性或非正义性。
- 结论。

## 六、具体答题思路与方法

### 1. 文字表达方式

- 字迹端正。
- 排列整齐。
- 疏密得当。
- 文句通顺。
- 语言准确。
- 一问一段。
- 一点一句。
- 序号清楚。

### 2. 分析变法或改革成败原因

- 看历史潮流和趋势是否支持改革。
- 看政策与措施是否正确，是否有效贯彻。
- 看新旧势力的力量对比。
- 看改革者的素质和能力。

### 3. 外显比较式问答题

- 先审清比较对象、比较项和限制条件。
- 再分析题目要求与课本知识的关系。
- 最后按设定项目逐项比较。

### 4. 内隐比较式问答题

- 根据题意自己确定比较对象和比较项。
- 比较事件时，常从背景、原因、过程、特点、结果、影响、性质等方面入手。
- 比较人物时，常从时代、阶级、功绩、局限、地位、影响等方面入手。

### 5. 比较项的确定

- 人物：国籍、时代、称谓、主要活动、评价。
- 事件：背景、时间、空间、主体、经过、意义。
- 现象：主要内容或主要表现。
- 制度：背景、时间、制定者、主要内容、评价。
- 革命：任务、领导、纲领、主力、方式、性质、结果。
- 革命结果及影响：进步性、局限性。

### 6. 分析经济特征型问答题

- 从复杂经济现象中概括基本特征。
- 分析特征形成的原因和影响。
- 表述要精炼，要源于教材、高于教材。

### 7. 归纳概括方法

- 归纳是把零散史实按同类梳理，使之由繁到简、由乱到整。
- 概括是把相同属性的历史事物联合起来，形成规律性认识。
- 归纳是概括的前提。

### 8. 开放性问答题

- 先确定观点。
- 再用史实支撑观点。
- 尽量少漏支持点。
- 史论结合，有论有据。
- 要全面，肯定积极作用时也要指出消极作用。

### 9. “说明了什么”类型问题

- 先看这种斗争的目的是什么。
- 再看有没有进步或倒退作用。
- 再判断这种斗争的失败是偶然还是必然。
- 如果是偶然，说明斗争曲折复杂，还要继续创造条件。
- 如果是必然，说明这种斗争的根本无法实现，是空想。

### 10. 论述题与史论结合

- 第一步，判断是非，表明观点。
- 第二步，列举史实，分子观点展开论证。
- 第三步，适当小结，升华观点。
- 史论结合的关键是：
  - 从史实中提炼观点。
  - 用观点统领史实。
  - 观点与史实统一。
